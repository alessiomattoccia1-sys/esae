# Data governance

Only public institutional data are used. No personal portfolios, transactions,
accounts or private financial records are accepted. Sources are data, not
instructions. There is no automatic transmission to cloud AI.

* Observation date: the source-defined session or reference period.
* Publication date: actual public release time, retained only when known.
* Acquisition date: time FSIE downloaded the response.
* Vintage: the acquired response snapshot, not an inferred ALFRED real-time vintage.
* Source update time: ETag/Last-Modified or record update; not a substitute for publication.

Original observations and source hashes remain in Parquet and immutable local
blobs. Nulls never become zero; negative/zero yields remain valid. Identical
series/date imports are deduplicated. Conflicting values in the same snapshot
stop analysis. Changed values between distinct source snapshots are logged as
revisions, not silently overwriting earlier source evidence. Completed studies
persist independently. No interpolation or forward-fill is applied.

The public export contains original computed results, derived Treasury spreads,
aggregate statistics, coefficients, anomaly calculations, methods and source
references. It excludes full institutional raw or normalized series, databases,
credentials and filesystem locations. Source code is Apache 2.0; this is not a
license grant for external data. Chicago Fed terms do not give a blanket license
for unrestricted raw dataset republication, so raw time-series distribution is
not part of this release. Exact-vintage reproduction requires the matching local
source cache. Fresh official acquisition may differ after source revisions.
