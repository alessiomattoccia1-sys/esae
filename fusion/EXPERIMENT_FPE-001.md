# FPE-001 — Magnetic Plasma Dynamics

Retrospective quantitative analysis of public MAST discharges. Source: UKAEA FAIR-MAST, documented official S3 catalog and selected diagnostic chunks. Deterministic cohort/window/method are in SCIENTIFIC_METHODOLOGY.md.

Questions: what temporal/spectral properties can be measured, which candidate features recur, and how sensitive are they to window/filter/threshold choices? The output categories are MCF-01 cohort/quality, MCF-02 signal features, and MCF-03 cross-shot dispersion and sensitivity. Each has input references, numerical payload, unit, method, uncertainty statement and limitations.

Read reports/fusion/FPE-001_REPORT.html, RESULTS.json, FINDINGS.csv, MANIFEST.json, METHODOLOGY.md and REPRODUCIBILITY.md. Scientific findings are generated from code and measurements, not manually inserted marketing numbers. See RESULTS.md for the qualified execution.
