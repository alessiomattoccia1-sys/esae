What was actually run

ESAE orchestrated Cppcheck 2.22.0 and clang-tidy 23.1.4 locally on a Mac mini M1, 16 GiB, macOS 27, Python 3.12. 186 unique files, 5,315,690 bytes; 85 source translation units and 101 project headers. Shared headers count once. System SDK headers are not included in the line count. All selected source hashes match the pinned upstream archive.

One unit and one native analyzer process at a time; 120 seconds per process, 300 seconds native budget per unit. A selected Mac arm64 C++11 configuration, with verified host predefines and explicitly absent foreign-platform macros. Native checks still run with bounded read-only snapshots, no network and mandatory macOS sandbox. No repository script or compilation command was executed during the benchmark. One selected Cppcheck configuration per compilation database entry; other platform configurations are not covered.

Measurement and repeatability

The full queue took 689.715 seconds, excluding source download, tool installation and unit preparation. Analyzer peak RSS was 565,968,896 bytes; controller peak RSS was 149,798,912 bytes. These are separate process high-water marks, not simultaneous total memory consumption.

85 / 85 units completed, 170 successful analyzer invocations, zero detected execution/configuration errors; original selected sources unchanged. Completion does not prove every code path was analyzed. The full run used the local hardening candidate recorded as 0.1.0. The two slowest units were repeated on final 0.1.1 code, with identical semantic diagnostic signatures. This is not a second full 85-unit run. The public reproduction command was separately stopped after one unit and resumed on the second without replay. 53 regression tests passed, zero failures or skips.

The initial limit remains visible

The initial single-job baseline used 30 seconds per process and a 300-second native budget: it stopped partially after 305.215 seconds, with 33 of 85 clang-tidy units completed and a Cppcheck timeout. The later qualification also corrected target macros and configuration selection; these figures are not a controlled speedup comparison. Godot's million-line repository was previously inventoried but not completely analyzed. No completed million-line result is claimed.

Reproduce locally

Download the ESAE 0.1.1 source, follow its explicit macOS setup, then run:

.venv/bin/python -m benchmarks.reproduce_cppcheck   --output .local/cppcheck-benchmark

Optionally add --max-new-units 5 and rerun the same command to resume. The example verifies the archive and source hashes and rejects changed engine/profile/toolchain checkpoints. It downloads public GPL-3.0-or-later source locally; no third-party source is included in the ESAE source distribution.

Explicit boundaries

Source limits remain 1,000 files / 50 MB and 2 MB per file per scan; default single-job native budget remains 300 seconds. The separate example orchestrates bounded scans. No whole-program cross-unit property, WCET, race-freedom, formal correctness or safety certification is verified. Native diagnostics require review and are not a count of confirmed bugs. No AI, cloud or user-code upload was used. Windows/Linux qualification is not implied.
