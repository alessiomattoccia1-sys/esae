# Reproducibility

Use the exact qualified lock, source commit and manifest working-file hashes. CLI run EXP creates persistent UUID job; reproduce UUID reads that manifest, rehashes all acquired bytes and reruns the original parser/mathematics offline. Results fingerprint excludes performance clocks but includes scientific fields, source identities, parameters and seeds. Missing/altered source bytes fail explicitly. Original ZIP selected-member CRC/size and raw-range checks are verified again. Reproduction output is a separate preserved folder.

Changing source availability, parser or parameters is a different analysis. Current source downloads can differ from old vintages; no claim the public package contains all original raw data. Cache raw bytes are needed for exact historical replay. State/observation/visibility streams and simulation checkpoint state are saved; deterministic numerical equivalence is qualified in the recorded NumPy/SciPy/platform environment, not promised bit-identical across arbitrary BLAS versions.
